METHODS NOTES — KDD AI4Mental 2026
Video-based Depression Assessment: Within- and Cross-Corpus Analysis
EmpkinS-EKSpression RCT <-> E-DAIC
================================================================================
Last updated: 2026-04-23

--------------------------------------------------------------------------------
1. DATASETS
--------------------------------------------------------------------------------

EmpkinS-EKSpression (EmpkinS):
  - N = 256 participants; RCT design; four conditions:
      AFE (ADK)       — active facial expression training
      CR+AFE (CRADK)  — cognitive reappraisal + AFE
      CR              — cognitive reappraisal only
      SHAM            — active control (no intervention)
  - Depression label: SCID-5-CV (0 = HC, 1 = MDD); administered by trained clinicians
  - Continuous targets: PHQ-8, PHQ-9, CES-D (ADS), HRSD-6, HRSD-17, HRSD-21, HRSD-24
  - Four task phases per participant:
      Latency          — passive waiting/baseline (camera-facing, no active task)
      Emotion Induction 1 — cognitive stressor
      Negative Training   — condition-specific training (negative affect focus)
      Positive Training   — condition-specific training (positive affect focus)
  - Video features: OpenFace 2.0; aggregated per participant per phase using
    18 statistical functionals (mean, std, min, max, median, IQR, skewness,
    kurtosis, range, 10th/25th/75th/90th percentiles, energy, entropy,
    autocorrelation, first-difference mean, zero-crossing rate)

E-DAIC (Extended Distress Analysis Interview Corpus):
  - N = 275 participants; clinical interview setting (Wizard-of-Oz virtual agent)
  - Official split: train=163, dev=56, test=56
  - Depression label: PHQ-8 >= 10 (binary; "depressed" column in dataset)
  - Continuous label: PHQ-8 score (PHQ_score column)
  - Class balance: train+dev ~78% non-depressed / 22% depressed; test ~70/30
  - Video features: OpenFace 2.0 (same feature set, same 18 functionals)
    aggregated to participant level

--------------------------------------------------------------------------------
2. FEATURE SET — 882 CROSS-CORPUS RESTRICTED FEATURES
--------------------------------------------------------------------------------

To enable cross-corpus transfer, only features extractable by OpenFace 2.0 and
present in both corpora are used. These are:

  - Facial Action Units (AUs): AU01, AU02, AU04, AU05, AU06, AU07, AU09, AU10,
    AU12, AU14, AU15, AU17, AU20, AU23, AU25, AU26, AU28, AU45
    Both intensity (_r, regression) and presence (_c, classification) variants
  - Gaze: gaze_angle_x, gaze_angle_y, gaze_0_x/y/z, gaze_1_x/y/z
  - Head pose: pose_Rx, pose_Ry, pose_Rz, pose_Tx, pose_Ty, pose_Tz

  Each feature x 18 statistical functionals = 882 features total.

  EmpkinS loads its full feature matrix (~20,000+ columns) and alignment to
  E-DAIC is achieved via column intersection (align_features()), which
  automatically reduces to the 882 common columns. All within-corpus nested CV
  results also use this restricted 882-feature set (--restrict-to-cross-corpus
  flag), ensuring direct comparability between within- and cross-corpus results.

  After alignment, a further feature selection step is applied on the training
  set only (no leakage):
    - Regression: Spearman rank correlation + Benjamini-Hochberg FDR correction
      (q = 0.20); fallback to top-20 by |r| if < 5 features survive
    - Classification: Mann-Whitney U test + Benjamini-Hochberg FDR (q = 0.20);
      fallback to top-20 by rank-biserial correlation |r|
  Followed by Recursive Feature Elimination (RFE) with a Ridge (regression) or
  Logistic Regression (classification) surrogate, k in {5, 10, 15, 20},
  optimised by 3-fold CV (MAE for regression, AUC for classification).

--------------------------------------------------------------------------------
3. EMPKINS TRAIN/TEST SPLITS
--------------------------------------------------------------------------------

A single fixed 80/20 stratified split is generated per condition (ADK, CRADK,
CR, SHAM) and for all conditions combined (ALL), stratified by SCID label.
Split files are stored at:
  .../affective_paper_final_revisions/classical_ML_fixed/scripts/
  shared_train_ids_{tag}.csv / shared_test_ids_{tag}.csv

Split sizes and class balance (SCID label):
  ADK:   train n=45  HC=21 MDD=24 (0.53)  /  test n=12  HC=6 MDD=6  (0.50)
  CRADK: train n=46  HC=22 MDD=24 (0.52)  /  test n=12  HC=6 MDD=6  (0.50) (note: NEG_CRADK test n=11 due to missing phase data for 1 participant)
  CR:    train n=47  HC=23 MDD=24 (0.51)  /  test n=12  HC=6 MDD=6  (0.50)
  SHAM:  train n=48  HC=24 MDD=24 (0.50)  /  test n=13  HC=6 MDD=7  (0.54)
  ALL:   train n=188 HC=91 MDD=97 (0.52)  /  test n=47  HC=23 MDD=24 (0.51)

The same split files are used identically across all analyses (within-corpus
regression, cross-corpus regression, SCID classification, PHQ-8>=10
classification), ensuring all comparisons are on the same participants.

Note on PHQ-8>=10 label balance (when used instead of SCID):
  Splits were stratified by SCID, not PHQ-8, so PHQ-8>=10 balance in the test
  sets varies (e.g. SHAM test: 10/13 = 77% positive; NEG_CRADK test: 5/11 = 45%
  positive) due to the small test set sizes. PHQ-8>=10 and SCID agree well at
  the group level but diverge for individual participants, especially in
  intervention conditions where treatment may have changed PHQ-8 but not SCID.

--------------------------------------------------------------------------------
4. WITHIN-CORPUS REGRESSION — NESTED CROSS-VALIDATION
--------------------------------------------------------------------------------

Design:
  - 5-fold outer cross-validation, stratified by SCID label
  - For ALL_CONDITIONS: stratified by condition + SCID jointly (8 strata:
    ADK_0, ADK_1, CRADK_0, CRADK_1, CR_0, CR_1, SHAM_0, SHAM_1) to ensure
    each fold contains all condition × label combinations
  - Inner loop: 3-fold GridSearchCV for hyperparameter tuning, fit on outer
    train fold only
  - Feature selection (Spearman FDR -> RFE) applied inside each outer fold
    on training data only (no leakage)

Targets: PHQ-8, PHQ-9, CES-D, HRSD-17
  (HRSD-6, HRSD-21, HRSD-24 also run but not included in the main table)

Models (all combinations tried per fold, best selected by mean CCC):
  Ridge, Lasso, ElasticNet, SVR (RBF), KNN, Random Forest, Extra Trees,
  Gradient Boosting, XGBoost, LightGBM, CatBoost, MLP
  Scalers: StandardScaler, RobustScaler

Primary metric: Lin's Concordance Correlation Coefficient (CCC).
  CCC = 2*r*sigma_x*sigma_y / (sigma_x^2 + sigma_y^2 + (mu_x - mu_y)^2)
  CCC combines Pearson r (precision) with mean/variance bias (accuracy).
  Range [-1, 1]; CCC=0 means no better than predicting the training mean.
  Best model per cell selected by mean CCC across the 5 folds (with MAE<100
  sanity filter to exclude degenerate linear models).
  Secondary metric reported: MAE.

Results table reports: mean +/- std CCC and mean +/- std MAE across 5 folds.
Bold CCC = best condition per phase row.

--------------------------------------------------------------------------------
5. CROSS-CORPUS EVALUATION — FIXED TRAIN/TEST SPLITS
--------------------------------------------------------------------------------

No cross-validation is used for cross-corpus evaluation. All experiments use
fixed train/test splits (EmpkinS: shared split files; E-DAIC: official split).

E-DAIC train set: train + dev splits combined (n=219); test set: official test
split (n=56). Dev participants are included in training following the standard
AVEC/E-DAIC challenge protocol.

EmpkinS source configurations (same for all three analysis types):
  Selected to cover two complementary views of the data:
  (a) Latency phase — passive observation, structurally closest to the E-DAIC
      clinical interview (no active task, camera-facing, spontaneous affect):
      LAT_ADK   — latency / AFE
      LAT_SHAM  — latency / SHAM (control; no treatment-induced facial changes)
      LAT_ALL   — latency / all conditions combined
  (b) Best training phase per condition (selected by highest within-corpus
      PHQ-8 CCC from nested CV results):
      POS_ADK   — positive training / AFE         (within-corpus CCC = .26)
      NEG_CRADK — negative training / CR+AFE      (within-corpus CCC = .09)
      NEG_CR    — negative training / CR          (within-corpus CCC = .20)
      NEG_SHAM  — negative training / SHAM        (within-corpus CCC = .26)

Experiment types (same structure for regression and both classification analyses):
  A : EmpkinS-ALL  -> E-DAIC-test
      Train on all available EmpkinS participants for that config;
      test on E-DAIC official test split (n=56).
      No EmpkinS holdout required since the test set is E-DAIC.
  C1: EmpkinS-train -> E-DAIC-test
      Train on EmpkinS 80% split; test on E-DAIC official test split.
      Proper train/test separation on both sides.
  B : E-DAIC -> EmpkinS-test
      Train on E-DAIC train+dev (n=219); test on EmpkinS 20% split.
      Tests whether clinical-interview models transfer to RCT tasks.
  D1: EmpkinS-train -> EmpkinS-test  [within-corpus baseline]
      Train on EmpkinS 80% split; test on EmpkinS 20% split.
      Upper bound for EmpkinS-side performance under the same feature/split setup.
  D2: E-DAIC-train -> E-DAIC-test  [within-corpus baseline]
      Train on E-DAIC train+dev (n=219); test on E-DAIC test (n=56).
      Upper bound for E-DAIC-side performance. Same result regardless of
      EmpkinS config (reported once, shown in all config columns).

  Note: C2 (E-DAIC-train -> EmpkinS-test) is identical to experiment B and
  is therefore not reported separately.

Session aggregation:
  For multi-session phases (negative_training, positive_training), EmpkinS
  participants contribute multiple rows (one per session). Before any train/test
  split or model fitting, all session rows for each participant are aggregated
  to a single participant-level row by taking the mean across sessions for
  features and first() for the label (which is constant per participant).
  This matches the within-corpus nested CV procedure exactly (groupby ID → mean),
  ensuring all analyses operate at the participant level and results are directly
  comparable. After aggregation: NEG_* configs have n_train~46, n_test~11;
  POS_* configs have n_train~45, n_test~12 — same as single-session configs.

Feature selection and model fitting procedure (same as within-corpus):
  For each experiment, feature selection (FDR -> RFE) is applied on the
  respective training set only, then all scaler x model combinations are
  evaluated. Best model selected by CCC (regression) or AUC (classification).

6. ANALYSIS TYPES
--------------------------------------------------------------------------------

6.1 Cross-corpus PHQ-8 Regression
  - EmpkinS target: PHQ-8 (continuous, 0-24)
  - E-DAIC target: PHQ_score (PHQ-8, continuous, 0-24)
  - Same scale, direct comparison possible
  - Primary metric: CCC; secondary: MAE

6.2 Cross-corpus Classification — SCID vs. PHQ-8>=10 labels
  - EmpkinS label: SCID-5-CV (gold standard; 0=HC, 1=MDD)
  - E-DAIC label:  PHQ-8 >= 10 (dataset standard; 0=non-depressed, 1=depressed)
  - Label definitions differ between corpora: SCID is a structured clinical
    interview, PHQ-8>=10 is a self-report threshold. This mismatch may reduce
    cross-corpus transfer beyond what feature distribution shift alone explains.
  - Primary metric: AUC-ROC; secondary: F1 (binary), balanced accuracy

6.3 Cross-corpus Classification — PHQ-8>=10 labels for both corpora
  - EmpkinS label: PHQ-8 >= 10 (same threshold as E-DAIC)
  - E-DAIC label:  PHQ-8 >= 10 (unchanged)
  - Removes the label mismatch present in 6.2; allows isolating whether
    cross-corpus difficulty is due to label inconsistency or feature distribution
    shift (domain gap).
  - Primary metric: AUC-ROC; secondary: F1 (binary), balanced accuracy

  Note on class balance mismatch:
  EmpkinS splits are stratified by SCID (~50/50 HC/MDD), while E-DAIC is
  heavily imbalanced (~78/22 non-dep/dep in train+dev, ~70/30 in test).
  Models trained on balanced EmpkinS data are calibrated for 50/50 prevalence;
  when applied to E-DAIC they face a lower base rate. The reverse direction
  (E-DAIC -> EmpkinS) produces a model biased towards non-depression that
  misses MDD cases in the balanced EmpkinS test set.
  Balanced accuracy is reported alongside AUC and F1 to account for this.

--------------------------------------------------------------------------------
7. METRICS SUMMARY
--------------------------------------------------------------------------------

Regression:
  CCC  — Lin's Concordance Correlation Coefficient (primary); range [-1, 1]
  MAE  — Mean Absolute Error (secondary); in PHQ-8 score units

Classification:
  AUC  — Area Under the ROC Curve (primary); range [0, 1]; 0.5 = chance
  F1   — Binary F1 score (positive class = depressed)
  BAcc — Balanced accuracy = (sensitivity + specificity) / 2

Within-corpus nested CV reports: mean +/- std across 5 outer folds.
Cross-corpus fixed-split reports: single value (no variance estimate, n_test fixed).
